# v7.15.0 Migration Guide

## Breaking Changes

### `accounts`

#### 1. AccountUpdateParams.Type removed

**What changed:**
The `Type` field is removed from `AccountUpdateParams`, along with the `AccountUpdateParamsType` enum
(`standard`, `enterprise`). `Accounts.Update()` no longer accepts an account `type`.

**Impact:**
Code that sets `AccountUpdateParams.Type` or references `AccountUpdateParamsType` no longer compiles.

**Removed Types:**
- `AccountUpdateParamsType` (and its `AccountUpdateParamsTypeStandard`, `AccountUpdateParamsTypeEnterprise` values)

**Before (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/accounts
acct, err := client.Accounts.Update(ctx, accounts.AccountUpdateParams{
    AccountID: cloudflare.F("account-id"),
    Name:      cloudflare.F("Example Account"),
    Type:      cloudflare.F(accounts.AccountUpdateParamsTypeStandard),
})
```

**After (v7.15.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/accounts
acct, err := client.Accounts.Update(ctx, accounts.AccountUpdateParams{
    AccountID: cloudflare.F("account-id"),
    Name:      cloudflare.F("Example Account"),
})
```

**Actions Needed:**
1. Remove the `Type` field from `AccountUpdateParams` construction.
2. Remove references to `AccountUpdateParamsType` and its values.

---

### `ssl`

#### 2. CertificatePackNewResponse simplified

**What changed:**
`CertificatePacks.New()` returns a simplified `CertificatePackNewResponse`. The `Certificates`,
`DCVDelegationRecords`, `ValidationErrors`, and `ValidationRecords` fields are removed, and their nested
types are deleted.

**Impact:**
Code reading those fields off the `CertificatePacks.New()` response, or referencing the removed nested
types, no longer compiles.

**Removed Types:**
- `CertificatePackNewResponseCertificate`
- `CertificatePackNewResponseCertificatesGeoRestrictions`
- `CertificatePackNewResponseCertificatesGeoRestrictionsLabel`
- `CertificatePackNewResponseDCVDelegationRecord`
- `CertificatePackNewResponseValidationError`
- `CertificatePackNewResponseValidationRecord`

**Before (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/ssl
pack, err := client.SSL.CertificatePacks.New(ctx, ssl.CertificatePackNewParams{
    ZoneID: cloudflare.F("zone-id"),
})
for _, cert := range pack.Certificates {
    _ = cert.Hosts
    _ = cert.GeoRestrictions.Label
}
_ = pack.ValidationRecords
_ = pack.DCVDelegationRecords
```

**After (v7.15.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/ssl
pack, err := client.SSL.CertificatePacks.New(ctx, ssl.CertificatePackNewParams{
    ZoneID: cloudflare.F("zone-id"),
})
// pack.Certificates, pack.DCVDelegationRecords, pack.ValidationErrors,
// and pack.ValidationRecords are no longer present on the response.
```

**Actions Needed:**
1. Remove reads of `Certificates`, `DCVDelegationRecords`, `ValidationErrors`, and `ValidationRecords`
   from the `CertificatePacks.New()` response.
2. Remove references to the removed nested types.

---

### `rules`

#### 3. ListCursor and ListCursorParam removed

**What changed:**
The `ListCursor` and `ListCursorParam` types are removed from the `rules` package. Method signatures on
`rules` are unchanged.

**Impact:**
Code that imports `rules.ListCursor` or `rules.ListCursorParam` directly no longer compiles.

**Removed Types:**
- `ListCursor`
- `ListCursorParam`

**Actions Needed:**
1. Remove direct references to `rules.ListCursor` and `rules.ListCursorParam`.

---

### `tenants`

#### 4. Accounts.List return type changed

**What changed:**
`Tenants.Accounts.List()` returns `*pagination.SinglePage[AccountListResponse]` instead of
`*pagination.V4PagePaginationArray[AccountListResponse]`. The endpoint no longer uses page-based pagination.

**Impact:**
Explicit references to the old `*pagination.V4PagePaginationArray[...]` return type no longer compile.
Code using inferred types and `ListAutoPaging()` continues to work.

**Before (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/tenants,
//          github.com/cloudflare/cloudflare-go/v7/packages/pagination
var page *pagination.V4PagePaginationArray[tenants.AccountListResponse]
page, err = client.Tenants.Accounts.List(ctx, "tenant-id", tenants.AccountListParams{})
```

**After (v7.15.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/tenants,
//          github.com/cloudflare/cloudflare-go/v7/packages/pagination
var page *pagination.SinglePage[tenants.AccountListResponse]
page, err = client.Tenants.Accounts.List(ctx, "tenant-id", tenants.AccountListParams{})
```

**Actions Needed:**
1. Update explicit return-type declarations from `*pagination.V4PagePaginationArray[tenants.AccountListResponse]`
   to `*pagination.SinglePage[tenants.AccountListResponse]`.

---

## Summary

1. **accounts** -- Remove `AccountUpdateParams.Type` and references to `AccountUpdateParamsType`.
2. **ssl** -- Remove reads of the dropped `CertificatePackNewResponse` fields and references to the removed nested types.
3. **rules** -- Remove references to `ListCursor` and `ListCursorParam`.
4. **tenants** -- Update explicit `Accounts.List()` return type to `*pagination.SinglePage[AccountListResponse]`.
