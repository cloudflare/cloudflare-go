# v7.14.0 Migration Guide

## Breaking Changes

### `magic_cloud_networking`

#### 1. MagicCloudNetworking service removed

**What changed:**
The entire `MagicCloudNetworking` service and the `github.com/cloudflare/cloudflare-go/v7/magic_cloud_networking`
package are removed. `client.MagicCloudNetworking` no longer exists.

**Impact:**
Any import of the `magic_cloud_networking` package or reference to `client.MagicCloudNetworking` no longer compiles.

**Removed Types:**
- `MagicCloudNetworkingService` and its `NewMagicCloudNetworkingService` constructor
- `CatalogSyncService`, `CloudIntegrationService`, `OnrampService`, and their sub-resources
- All associated response and parameter types in the `magic_cloud_networking` package

**Before (v7.13.1):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/magic_cloud_networking
res, err := client.MagicCloudNetworking.CloudIntegration.List(ctx, magic_cloud_networking.CloudIntegrationListParams{
    AccountID: cloudflare.F("account-id"),
})
```

**After (v7.14.0):**
```go
// No replacement. Remove the import and all call sites.
```

**Actions Needed:**
1. Remove the `magic_cloud_networking` import and all `client.MagicCloudNetworking.*` call sites.
2. Remove references to any `magic_cloud_networking.*` types.

**What changed:**

**Impact:**
Code that ranged over the returned slice no longer compiles.

**Removed Types:**
- `SubscriptionBulkNewResponseEnvelopeResultInfo`

**Before (v7.13.1):**

```go
//          github.com/cloudflare/cloudflare-go/v7/accounts

    AccountID: cloudflare.F("account-id"),
})
```

**After (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/accounts

res, err = client.Accounts.Subscriptions.Bulk.New(ctx, accounts.SubscriptionBulkNewParams{
    AccountID: cloudflare.F("account-id"),

```

**Actions Needed:**
1. Change the declared return type from `*[]accounts.SubscriptionBulkNewResponse` to `*accounts.SubscriptionBulkNewResponse`.
2. Remove any loop over the former slice result.

### `diagnostics`

**What changed:**
`Diagnostics.EndpointHealthchecks.List()` returns `*pagination.SinglePage[diagnostics.EndpointHealthcheckListResponse]`
instead of `*diagnostics.EndpointHealthcheckListResponse`.

**Impact:**
Call sites referencing the return value by type must update, and results are now iterated as a page.

**Removed Types:**
- `EndpointHealthcheckListResponseEnvelope` and its nested `Errors`, `ErrorsSource`, `Messages`, `MessagesSource`, and `Success` types

```go
res, err = client.Diagnostics.EndpointHealthchecks.List(ctx, diagnostics.EndpointHealthcheckListParams{
    AccountID: cloudflare.F("account-id"),
})
```

**After (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/diagnostics,
//          github.com/cloudflare/cloudflare-go/v7/packages/pagination
page, err := client.Diagnostics.EndpointHealthchecks.List(ctx, diagnostics.EndpointHealthcheckListParams{
    AccountID: cloudflare.F("account-id"),
```

```go
var res *[]organizations.OrganizationAccountGetResponse
res, err = client.Organizations.OrganizationAccounts.Get(ctx, "organization-id",
    organizations.OrganizationAccountGetParams{})
```

1. Change the element type from `tenants.TenantAccount` to `organizations.OrganizationAccountGetResponse`.

### `rulesets`

#### 11. Ruleset response models consolidated into unions

**What changed:**
Ruleset responses now use union types. The following methods return `*...ResponseUnion` instead of their previous
`*...ResponseEnvelopeResult` or paginated types:

| Method | Before (v7.13.1) | After (v7.14.0) |
|---|---|---|
| `Rulesets.New()` | `*RulesetNewResponseEnvelopeResult` | `*RulesetNewResponseUnion` |
| `Rulesets.Update()` | `*RulesetUpdateResponseEnvelopeResult` | `*RulesetUpdateResponseUnion` |
| `Rulesets.List()` | `*pagination.CursorPagination[RulesetListResponse]` | `*RulesetListResponseUnion` |
| `Rulesets.Phases.Update()` | `*PhaseUpdateResponseEnvelopeResult` | `*PhaseUpdateResponseUnion` |
| `Rulesets.Phases.Versions.List()` | `*pagination.SinglePage[PhaseVersionListResponse]` | `*PhaseVersionListResponseUnion` |
| `Rulesets.Rules.New()` | `*RuleNewResponseEnvelopeResult` | `*RuleNewResponseUnion` |
| `Rulesets.Rules.Delete()` | `*RuleDeleteResponseEnvelopeResult` | `*RuleDeleteResponseUnion` |
| `Rulesets.Rules.Edit()` | `*RuleEditResponseEnvelopeResult` | `*RuleEditResponseUnion` |
| `Rulesets.Versions.List()` | `*pagination.SinglePage[VersionListResponse]` | `*VersionListResponseUnion` |

**Impact:**
Call sites referencing these return values by type no longer compile. `Rulesets.List()` and
`Phases.Versions.List()`/`Versions.List()` are no longer paginated; iterate the union result instead of paging.

**Removed Types:**
- `RulesetListResponse`, `PhaseVersionListResponse`, `VersionListResponse`
- The `VersionGetResponse*` and `PhaseVersionGetResponse*` rule type trees
- The per-method `*ResponseEnvelopeResult` types

**Before (v7.13.1):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/rulesets
var res *rulesets.RulesetNewResponseEnvelopeResult
res, err = client.Rulesets.New(ctx, rulesets.RulesetNewParams{
    AccountID: cloudflare.F("account-id"),
})
```

**After (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/rulesets
var res *rulesets.RulesetNewResponseUnion
res, err = client.Rulesets.New(ctx, rulesets.RulesetNewParams{
    AccountID: cloudflare.F("account-id"),
})
```

**Actions Needed:**
1. Replace `*...ResponseEnvelopeResult` type references with the corresponding `*...ResponseUnion` types.
2. For `List()` methods that were paginated, stop paging and read the returned union directly.
3. Switch on the union variants where you previously read concrete envelope-result fields.

### `tenants`

#### 12. Multiple tenants methods and types removed; Accounts.List changed

**What changed:**
- `Tenants.Get()` is removed, along with the `Tenant` type and its nested types.
- `Tenants.AccountTypes.List()` is removed.
- `Tenants.Entitlements.Get()` is removed, along with the `TenantEntitlements` type and its nested types.
- `Tenants.Memberships.List()` is removed, along with the `TenantMembership` type.
- `Tenants.Accounts.List()` now takes a `query tenants.AccountListParams` argument and returns
  `*pagination.V4PagePaginationArray[tenants.AccountListResponse]` instead of
  `*pagination.SinglePage[tenants.TenantAccount]`.

**Impact:**
The removed calls and types no longer compile. `Accounts.List()` call sites must pass a params argument and update
the element type.

**Removed Types:**
- `Tenant` (and its nested `TenantTenant*` types)
- `TenantEntitlements` (and its nested types)
- `TenantMembership`

**Before (v7.13.1):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7/tenants
page, err := client.Tenants.Accounts.List(ctx, "tenant-id")
// page is *pagination.SinglePage[tenants.TenantAccount]
```

**After (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7/tenants
page, err := client.Tenants.Accounts.List(ctx, "tenant-id", tenants.AccountListParams{})
// page is *pagination.V4PagePaginationArray[tenants.AccountListResponse]
```

**Actions Needed:**
1. Remove calls to `Tenants.Get()`, `Tenants.AccountTypes.List()`, `Tenants.Entitlements.Get()`, and
   `Tenants.Memberships.List()`, and references to `Tenant`, `TenantEntitlements`, and `TenantMembership`.
2. Add the `tenants.AccountListParams` argument to `Tenants.Accounts.List()` and change the element type from
   `tenants.TenantAccount` to `tenants.AccountListResponse`.

### `zones`

#### 18. Zone setting value types restructured into unions

**What changed:**
The concrete per-setting `Value` enum types are removed and replaced by `*ValueUnion` interfaces and `*ValueArray`
types. For example, `HTTP2Value` (a `string` enum) is replaced by `HTTP2ValueUnion` (and `HTTP2ValueArray`). This
applies to roughly 80 setting value types, including the `SettingEditResponseZones*Value` and
`SettingGetResponseZones*Value` families. The `AutomaticPlatformOptimization` response struct is removed; the
`AutomaticPlatformOptimizationParam` type is retained.

**Impact:**
Code that read or constructed setting values using the concrete enum types no longer compiles.

**Removed Types (representative):**
- `HTTP2Value`, `HTTP3Value`, `BrotliValue`, `MinTLSVersionValue`, `IPV6Value`, `TLS1_3Value`, `WebsocketValue`,
  `ZeroRTTValue`, `EarlyHintsValue`, `ImageResizingValue`, and the other `*Value` setting enums
- The `SettingEditResponseZones*Value` and `SettingGetResponseZones*Value` type families
- `AutomaticPlatformOptimization` (response struct)

**Before (v7.13.1):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7/zones
var v zones.HTTP2Value = zones.HTTP2ValueOn
_ = v
```

**After (v7.14.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7/zones
// HTTP2Value is removed; the setting Value is now a union.
// Read it via the HTTP2ValueUnion interface and switch on the concrete variant.
```

**Actions Needed:**
1. Replace concrete `*Value` enum references with the corresponding `*ValueUnion` interfaces (and `*ValueArray`
   where the value is a list).
2. Switch on the union variants when reading setting values.
3. Remove references to the `AutomaticPlatformOptimization` response struct.

## Summary

1. **magic_cloud_networking** -- The entire `MagicCloudNetworking` service and package are removed; no replacement.
2. **accounts** -- `PayBadDebt` removed; `Subscriptions.Bulk.New()` returns a single response; param helper types removed.
3. **diagnostics** -- `EndpointHealthchecks.List()` now returns a `SinglePage`.
4. **magic_transit** -- `WANStaticAddressingParam` removed.
5. **organizations** -- `OrganizationAccounts.Get()` and `Members.Delete()` signatures changed; param helper types removed.
6. **precursor** -- `EnforcementRule*` and `PrecursorConfigDefaultMode` removed.
7. **rulesets** -- Response models consolidated into union types; `List()` methods no longer paginated.
8. **tenants** -- `Get()`, `AccountTypes.List()`, `Entitlements.Get()`, and `Memberships.List()` removed;
   `Accounts.List()` now takes params and returns `V4PagePaginationArray`.
9. **tenant_custom_nameservers** -- All methods removed; service exposes nothing.
10. **user** -- `Tenants.List()` element type changed to `user.TenantListResponse`.
11. **vectorize** -- `Indexes.GetByIDs()` now returns a `SinglePage`.
12. **zero_trust** -- `ResourceLibrary` list methods now cursor-paginated; DLP entry update body and Gateway
    audit-SSH types removed.
13. **zones** -- Setting value enum types replaced by union types; `AutomaticPlatformOptimization` response struct removed.
