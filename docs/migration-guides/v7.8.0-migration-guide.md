# v7.8.0 Migration Guide

## Breaking Changes

### `acm`

#### 1. CertificateAuthority type removed

**What changed:**
The `CertificateAuthority` type has been removed from both the params and response type lists in the `acm` package.

**Impact:**
Code referencing `acm.CertificateAuthority` directly will no longer compile. The `TotalTLS` methods themselves are unchanged.

**Removed Types:**
- `acm.CertificateAuthority` (param type)
- `acm.CertificateAuthority` (response type)

**Actions Needed:**
1. Remove any direct references to `acm.CertificateAuthority`.
2. Use the per-method response types (`TotalTLSUpdateResponse`, `TotalTLSEditResponse`, `TotalTLSGetResponse`) instead.

---

### `brand_protection`

#### 2. V2.Queries.Get return type changed to union

**What changed:**
The `V2.Queries.Get()` method now returns `*V2QueryGetResponseUnion` instead of `*[]V2QueryGetResponse`. The `V2QueryGetResponse` type has been removed.

**Impact:**
Code that iterates over the returned slice or references `V2QueryGetResponse` by name will no longer compile.

**Removed Types:**
- `V2QueryGetResponse`

**Before (v7.7.0):**
```go
results, err := client.BrandProtection.V2.Queries.Get(ctx, params)
for _, r := range *results {
    fmt.Println(r.ID)
}
```

**After (v7.8.0):**
```go
result, err := client.BrandProtection.V2.Queries.Get(ctx, params)
// Handle the union type
switch v := result.AsUnion().(type) {
case brand_protection.V2QueryGetResponseVariant:
    // handle variant
}
```

**Actions Needed:**
1. Update all `V2.Queries.Get` call sites to handle the union return type.
2. Replace `V2QueryGetResponse` type references with `V2QueryGetResponseUnion`.

---

### `certificate_authorities`

#### 3. HostnameAssociationParam and HostnameAssociation types removed

**What changed:**
The shared `HostnameAssociationParam` (param) and `HostnameAssociation` (response) types have been removed.

**Impact:**
Code referencing these types directly will no longer compile. The methods themselves are unchanged.

**Removed Types:**
- `certificate_authorities.HostnameAssociationParam`
- `certificate_authorities.HostnameAssociation`

**Actions Needed:**
1. Use `TLSHostnameAssociationParam` for params.
2. Use `HostnameAssociationUpdateResponse` and `HostnameAssociationGetResponse` for responses.

---

### `cloudforce_one`

#### 4. ThreatEvents.IndicatorTypes relocated to ThreatEvents.Indicators.Types

**What changed:**
The `IndicatorTypes` sub-resource moved from `ThreatEvents.IndicatorTypes` to `ThreatEvents.Indicators.Types`. The endpoint path changed from `/events/indicatorTypes` to `/events/indicator-types`.

**Impact:**
Code accessing `client.CloudforceOne.ThreatEvents.IndicatorTypes.List(...)` will no longer compile.

**Before (v7.7.0):**
```go
result, err := client.CloudforceOne.ThreatEvents.IndicatorTypes.List(ctx,
    cloudforce_one.ThreatEventIndicatorTypeListParams{
        AccountID: cloudflare.F("account-id"),
    },
)
```

**After (v7.8.0):**
```go
result, err := client.CloudforceOne.ThreatEvents.Indicators.Types.List(ctx,
    cloudforce_one.ThreatEventIndicatorTypeListParams{
        AccountID: cloudflare.F("account-id"),
    },
)
```

**Actions Needed:**
1. Change `ThreatEvents.IndicatorTypes` to `ThreatEvents.Indicators.Types` at all call sites.

---

### `hyperdrive`

#### 6. Configs.List pagination type changed

**What changed:**
`Configs.List()` now returns `*V4PagePaginationArray[Hyperdrive]` instead of `*SinglePage[Hyperdrive]`. The second parameter name changed from `query` to `params`.

**Impact:**
Code referencing the pagination type by name or using `SinglePage`-specific APIs will need updating. Basic iteration via `ListAutoPaging()` continues to work.

**Before (v7.7.0):**
```go
page, err := client.Hyperdrive.Configs.List(ctx, hyperdrive.ConfigListParams{
    AccountID: cloudflare.F("account-id"),
})
// page is *pagination.SinglePage[hyperdrive.Hyperdrive]
```

**After (v7.8.0):**
```go
page, err := client.Hyperdrive.Configs.List(ctx, hyperdrive.ConfigListParams{
    AccountID: cloudflare.F("account-id"),
})
// page is *pagination.V4PagePaginationArray[hyperdrive.Hyperdrive]
```

**Actions Needed:**
1. Update any explicit `SinglePage` type references to `V4PagePaginationArray`.
2. `ListAutoPaging()` iteration is unchanged.

### `moq`

#### 7. Relays.Tokens.Rotate replaced by CRUD methods

**What changed:**
The `Rotate()` method on `Relays.Tokens` has been removed. It is replaced by `New()`, `List()`, and `Delete()` methods.

**Impact:**
Code calling `Relays.Tokens.Rotate(...)` will no longer compile.

**Removed Types:**
- `RelayTokenRotateResponse`
- `RelayTokenRotateParams`

**Before (v7.7.0):**
```go
token, err := client.MoQ.Relays.Tokens.Rotate(ctx, "relay-id", moq.RelayTokenRotateParams{
    AccountID: cloudflare.F("account-id"),
})
```

**After (v7.8.0):**
```go
token, err := client.MoQ.Relays.Tokens.New(ctx, "relay-id", moq.RelayTokenNewParams{
    AccountID: cloudflare.F("account-id"),
})
```

**Actions Needed:**
1. Replace `Tokens.Rotate` calls with `Tokens.New`.
2. Update type references from `RelayTokenRotateResponse` to `RelayTokenNewResponse`.

---

### `mtls_certificates`

#### 8. Shared MTLSCertificate response type removed

**What changed:**
The shared `MTLSCertificate` response type has been removed. Each method now returns a dedicated response type.

**Impact:**
Code referencing `MTLSCertificate` by name will no longer compile.

**Removed Types:**
- `MTLSCertificate`

**Before (v7.7.0):**
```go
var cert *mtls_certificates.MTLSCertificate
cert, err = client.MTLSCertificates.Get(ctx, "cert-id", params)
```

**After (v7.8.0):**
```go
var cert *mtls_certificates.MTLSCertificateGetResponse
cert, err = client.MTLSCertificates.Get(ctx, "cert-id", params)
```

**Actions Needed:**
1. Replace `MTLSCertificate` with `MTLSCertificateGetResponse`, `MTLSCertificateListResponse`, or `MTLSCertificateDeleteResponse` depending on the method.

---

### `ssl`

#### 9. Host, HostParam, Status, and ValidationMethod types removed

**What changed:**
Four types have been removed from the `ssl` package: `HostParam` (param), `Host`, `Status`, and `ValidationMethod` (response).

**Impact:**
Code referencing these types directly will no longer compile.

**Removed Types:**
- `ssl.HostParam`
- `ssl.Host`
- `ssl.Status`
- `ssl.ValidationMethod`

**Actions Needed:**
1. Remove direct references to these types.
2. Use the per-method response types (`CertificatePackNewResponse`, `CertificatePackListResponse`, etc.) instead.

---

### `zero_trust`

#### 10. Casb.Applications.SetupFlows renamed to AuthMethods

**What changed:**
The `SetupFlows` sub-resource under `Casb.Applications` has been renamed to `AuthMethods`. The `Applications.Get()` path parameter changed from `slug` to `applicationID`.

**Impact:**
Code using `Applications.SetupFlows` or passing a `slug` parameter to `Applications.Get` will no longer compile.

**Removed Types:**
- `CasbApplicationSetupFlowListResponse`
- `CasbApplicationSetupFlowListParams`
- `CasbApplicationSetupFlowService`
- `CasbApplicationGetParamsSlug`

**Before (v7.7.0):**
```go
flows, err := client.ZeroTrust.Casb.Applications.SetupFlows.List(ctx, "my-app-slug",
    zero_trust.CasbApplicationSetupFlowListParams{
        AccountID: cloudflare.F("account-id"),
    },
)

app, err := client.ZeroTrust.Casb.Applications.Get(ctx,
    zero_trust.CasbApplicationGetParamsSlug("my-app-slug"),
    zero_trust.CasbApplicationGetParams{
        AccountID: cloudflare.F("account-id"),
    },
)
```

**After (v7.8.0):**
```go
methods, err := client.ZeroTrust.Casb.Applications.AuthMethods.List(ctx,
    zero_trust.CasbApplicationAuthMethodListParamsApplicationID("app-id"),
    zero_trust.CasbApplicationAuthMethodListParams{
        AccountID: cloudflare.F("account-id"),
    },
)

app, err := client.ZeroTrust.Casb.Applications.Get(ctx,
    zero_trust.CasbApplicationGetParamsApplicationID("app-id"),
    zero_trust.CasbApplicationGetParams{
        AccountID: cloudflare.F("account-id"),
    },
)
```

**Actions Needed:**
1. Rename `SetupFlows` to `AuthMethods` at all call sites.
2. Replace `CasbApplicationGetParamsSlug` with `CasbApplicationGetParamsApplicationID`.
3. Update type references from `CasbApplicationSetupFlowListResponse` to `CasbApplicationAuthMethodListResponse`.
