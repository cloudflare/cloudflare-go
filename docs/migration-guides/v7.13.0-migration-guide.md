# v7.13.0 Migration Guide

## Breaking Changes

### `registrar`

#### 1. Registrar.Domains sub-resource removed

**What changed:**
The `Domains` sub-resource and its `Update()`, `List()`, `ListAutoPaging()`, and `Get()` methods are removed
from `RegistrarService`. These endpoints reached end of life on September 27, 2026.

**Impact:**
Calls to `client.Registrar.Domains` and references to its removed types no longer compile.

**Removed Types:**
- `DomainService` and its `NewDomainService` constructor
- `Domain` and its nested response types
- `DomainUpdateResponse` and its nested response and envelope types
- `DomainGetResponse` and its nested response and envelope types
- `DomainUpdateParams`, `DomainListParams`, and `DomainGetParams`

**Before (v7.12.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/registrar
page, err := client.Registrar.Domains.List(ctx, registrar.DomainListParams{
    AccountID: cloudflare.F("account-id"),
})
domain, err := client.Registrar.Domains.Get(ctx, "example.com", registrar.DomainGetParams{
    AccountID: cloudflare.F("account-id"),
})
result, err := client.Registrar.Domains.Update(ctx, "example.com", registrar.DomainUpdateParams{
    AccountID: cloudflare.F("account-id"),
    AutoRenew: cloudflare.F(true),
})
```

**After (v7.13.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/registrar
page, err := client.Registrar.Registrations.List(ctx, registrar.RegistrationListParams{
    AccountID: cloudflare.F("account-id"),
})
domain, err := client.Registrar.Registrations.Get(ctx, "example.com", registrar.RegistrationGetParams{
    AccountID: cloudflare.F("account-id"),
})
result, err := client.Registrar.Registrations.Edit(ctx, "example.com", registrar.RegistrationEditParams{
    AccountID: cloudflare.F("account-id"),
    AutoRenew: cloudflare.F(true),
})
```

**Actions Needed:**
1. Replace `Domains.List()` and `Get()` with `Registrations.List()` and `Get()`, using the corresponding params.
2. Replace auto-renew updates with `Registrations.Edit()`. This endpoint currently supports only `auto_renew`;
   other legacy domain updates have no direct replacement through this method.
3. Update explicit response types: `List()` returns `*pagination.CursorPagination[registrar.Registration]`,
   `Get()` returns `*registrar.Registration`, and `Edit()` returns `*registrar.WorkflowStatus`.
4. Handle cursor pagination when listing and workflow completion when editing. An edit may require polling
   the returned workflow's `links.self` URL.
5. Remove references to the deleted `Domain*` types and constructor.

### `zero_trust`

#### 2. Access.Users.LastSeenIdentity.Get return type changed

**What changed:**
`Access.Users.LastSeenIdentity.Get()` returns `*AccessUserLastSeenIdentityGetResponse` instead of `*Identity`.
The response and its nested types are renamed. A new `Passkeys` field is also available.

**Impact:**
Explicit references to `zero_trust.Identity` and its nested types no longer compile.
Call sites using inferred return types generally need no changes.

**Affected Types (renamed):**

| Before (v7.12.0) | After (v7.13.0) |
|---|---|
| `Identity` | `AccessUserLastSeenIdentityGetResponse` |
| `IdentityDeviceSession` | `AccessUserLastSeenIdentityGetResponseDeviceSession` |
| `IdentityDevicePosture` | `AccessUserLastSeenIdentityGetResponseDevicePosture` |
| `IdentityDevicePostureCheck` | `AccessUserLastSeenIdentityGetResponseDevicePostureCheck` |
| `IdentityGeo` | `AccessUserLastSeenIdentityGetResponseGeo` |
| `IdentityIdP` | `AccessUserLastSeenIdentityGetResponseIdP` |
| `IdentityMTLSAuth` | `AccessUserLastSeenIdentityGetResponseMTLSAuth` |

**Before (v7.12.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/zero_trust
var identity *zero_trust.Identity
identity, err = client.ZeroTrust.Access.Users.LastSeenIdentity.Get(ctx, "user-id",
    zero_trust.AccessUserLastSeenIdentityGetParams{
        AccountID: cloudflare.F("account-id"),
    },
)
```

**After (v7.13.0):**
```go
// Imports: github.com/cloudflare/cloudflare-go/v7 (cloudflare),
//          github.com/cloudflare/cloudflare-go/v7/zero_trust
var identity *zero_trust.AccessUserLastSeenIdentityGetResponse
identity, err = client.ZeroTrust.Access.Users.LastSeenIdentity.Get(ctx, "user-id",
    zero_trust.AccessUserLastSeenIdentityGetParams{
        AccountID: cloudflare.F("account-id"),
    },
)
```

**Actions Needed:**
1. Replace explicit `Identity` type references using the table above.
2. Update any maps, slices, or struct fields using the renamed nested types.

---

## Summary

1. **registrar** -- Replace the removed `Domains` resource with `Registrations` and update response handling.
2. **zero_trust** -- Replace explicit `Identity` references with `AccessUserLastSeenIdentityGetResponse`
   and its nested types.
